ITE AD JOSEPH — 90-day reset for Catholic fathers (phone web app)

Put it online (about 5 minutes, free):
Option A — Netlify Drop
  1. Unzip this folder.
  2. Go to https://app.netlify.com/drop and sign in (free account).
  3. Drag the whole "iteadjoseph" folder onto the page.
  4. Netlify gives you a link. In Site settings you can rename it, e.g. iteadjoseph.netlify.app.
Option B — Cloudflare Pages (Workers & Pages > Create > Pages > Upload assets), same folder.

Install on a phone:
  iPhone: open the link in Safari > Share > Add to Home Screen.
  Android: open in Chrome > menu > Install app.

Daily reminder: in the app, Setup > Add to my calendar (adds all 91 days at the chosen time).

Files:
  index.html, app.js, styles.css  the app
  content.json                    all 91 days of text (edit here to change wording)
  audio/dayNN.m4a                 the 91 recorded sessions
  sw.js, manifest.webmanifest     offline + install support
Progress is stored only on each father's phone. No accounts, no server, no data collection.
